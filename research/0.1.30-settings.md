# 0.1.30-dev portable INI preferences

All MCM preferences are owned by Data/SKSE/Plugins/PickpocketOverhaul.ini and MCM setters write them immediately. Settings keys: KarmaMode, InventoryOpeningPenalty, EquippedItemDrops, WitnessStrength, StolenTagDays, AbsoluteMaximum, RecognitionDays, DistanceMultiplier. Debug/Enabled controls the witness percentage display. Copy this file into another setup's matching path, then load a save or restart Skyrim. With a virtualized mod manager, copy the effective edited file (often its overwrite/output folder), not an untouched copy in the download archive. Back it up before replacing it during updates.

Settings are centrally read on plugin startup and save/new-game reset. Co-save loading cannot overwrite preferences. Native defaults are reinstated before reading missing INI keys, preventing values from another loaded character leaking into missing settings. Perk compatibility still temporarily determines the effective maximum while preserving the editable INI maximum for setups without the perk overhaul. Unavailable transfer hooks do not erase the user's equipped-drop preference.

Karma record version 3 stores credit only (4 bytes). Drop recovery record version 2 stores count plus recovery entries, without a preference byte. Older karma v1/v2 and drop v1 records are still read: their history/recovery is restored, and their old preference bytes are validated then ignored. Other gameplay records remain unchanged. Failed/successful theft state, ownership and recognition deadlines, bump state and pending recoveries remain character/save-specific.

Build/regression tests pass. Settings ownership audit checks all shipped keys, MCM setter write paths, new and legacy serialization ownership, and centralized load callsites. Actual cross-install transfer and loading older co-saves still require gameplay testing.
