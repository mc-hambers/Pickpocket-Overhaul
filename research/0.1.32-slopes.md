# 0.1.32-dev slope drop placement

The previous redirected transfer forced an item origin at actor position +8 Z. That does not establish that the item's collision shape is above sloped terrain, particularly for armor with offsets/extents below the origin. The reported fall-through is consistent with an embedded initial shape, but no physics trace or live reproduction proves this was the only cause.

Redirected equipped drops now call the NPC's native Actor::DropObject with no custom position or rotation. Skyrim controls its default placement and physics setup, instead of the manually forced near-ground origin. The original extra-data instance and single count are passed through. The intercepted RemoveItem member's hidden return storage is initialized with std::construct_at, not assigned while uninitialized. No object is copied/spawned, and no post-drop teleport or continuous physics correction is added. Existing matching, ownership assignment, path recovery, native pickup and co-save bookkeeping remain.

Build/loader/export/package checks and existing behavior regressions pass. The source contract verifies native drop delegation and removal of the +8 placement. Actual slope, stair, rock, flat-floor and modded armor collision tests are still pending. Broken ground-item collision meshes can remain a separate cause; do not claim that every mesh/terrain issue is fixed without gameplay tests.
